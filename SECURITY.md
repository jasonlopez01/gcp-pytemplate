# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Use GitHub's private disclosure flow instead:

1. Go to the [Security tab](https://github.com/jasonlopez01/gcp-pytemplate/security/advisories/new)
2. Click **Report a vulnerability**
3. Fill in the details and submit

## What to Include

- Description of the vulnerability and its potential impact
- Steps to reproduce
- Affected versions or components
- Any suggested mitigations, if known

## Response

You can expect an acknowledgement within **15 business days** and a resolution timeline once the report has been triaged.
